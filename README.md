# Капля

Браузерная физическая игра о дождевой капле на стекле движущегося транспорта. Игрок ведет каплю к выходу на краю стекла, а вес, встречный ветер и инерция меняются вместе с движением машины за стеклом.

Игра создана в рамках Большого домашнего задания по курсу «Генеративный искусственный интеллект: модели и приложения» (НИЯУ МИФИ). Код сгенерирован методом вайбкодинга на платформе WebSim, концепция, техническое задание и документация подготовлены с применением генеративного ИИ.

**Играть онлайн** https://websim.com/p/ox7kilbeufyiaqhq7eoh

## Об игре

Новизна игры в том, что стекло движется. На лобовом стекле законы движения капли зависят от скорости машины, и игрок предугадывает их по светофорам и остановкам впереди. На боковом окне автобуса каплю сносит инерция при разгоне и торможении, а выйти нужно на своей остановке.

| Глава | Уровни | Механики |
|---|---|---|
| Лобовое стекло | Парковка, Трасса, Ночь | Прилипание и срыв капли, встречный ветер, слияние капель, мокрые следы, дворники, лед и пар |
| Автобус | Цветочная, Пробка, Парк | Инерция при разгоне и торможении, действие «держаться», впитывающий уплотнитель, выход на нужной остановке |

Чем больше капля, тем больше в ней воды, но тем хуже она слушается. Оценка от одной до трех звезд зависит от того, сколько воды капля донесла до выхода.

## Управление

| Клавиша | Действие |
|---|---|
| ← → или A D | Вести каплю |
| Кнопка мыши | Вести каплю к указателю |
| ↓ или S | Держаться за стекло (сильнее прилипание, быстрее испарение) |
| 1, 2 | Выбор главы |
| Enter | Продолжить |
| R | Перезапустить уровень |

## Запуск локально

Игра состоит из трех файлов без внешних библиотек. Файл `game.js` подключается как модуль, поэтому страницу нужно открывать через локальный веб-сервер, а не двойным щелчком.

```bash
cd game
python3 -m http.server 8000
```

Затем открыть в браузере http://localhost:8000

## Структура репозитория

```
game/          код игры из WebSim, версия 12 (index.html, style.css, game.js)
prompts/       исходный промпт для WebSim и журнал запросов по версиям
tests/         сценарий автоматизированных испытаний и его отчеты
```

## Применение генеративного ИИ

| Этап | Метод | Результат |
|---|---|---|
| 1. Идея | Коллективная мета-модерация, ИИ моделировал участников мозгового штурма | Три концепции доведены до прототипов, выбрана «Капля» |
| 2. Техническое задание | Мета-фасилитация Agile-команды, метапромптинг | ТЗ по ГОСТ, промпт для генерации кода, проверенный прототипом |
| 3. Реализация | Вайбкодинг в WebSim | 12 версий, опубликована версия 12 |
| 4. Документация | Анализ кода, автоматизированные испытания | Изменение 1 к ТЗ, пояснительная записка |

Журнал версий WebSim приведен в файле `prompts/zhurnal_websim.md`, подробный журнал по всем этапам в пояснительной записке, переданной преподавателю. Код игры вручную не правился, все изменения внесены запросами к WebSim.

## Испытания

Сценарий `tests/run.js` запускает игру в Chromium без интерфейса и на каждом уровне проводит случайную игру и игру ботом, который ведет каплю к выходу. Проверяется, что капля не выходит за стекло и не проникает в препятствия, что каждый уровень проходим и что в консоли нет ошибок. Файлы игры при этом не меняются.

```bash
npm install playwright
npx playwright install chromium
node tests/run.js
```

Отчет записывается в `tests/report_latest.json`. Отчет прогона, результаты которого приведены в пояснительной записке, сохранен в `tests/report_pz.json`. Случайная игра дает немного разные числа при каждом запуске.

## Планы

По техническому заданию запланированы еще две главы, «Теплица» и «Окно квартиры и утро», а также звук дождя и сохранение прогресса. При испытаниях найдено, что на уровне «Трасса» после 62 с нет ограничения времени, а экран завершения главы «Автобус» показывает звезды только последнего уровня. Эти особенности вынесены в план развития.
